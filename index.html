1. Parábola Vértice y Raíces

Ecuación ordinaria $y = a(x - h)^2 + k$. Vértice en $(h, k)$.

Si y = -0.5x² + 8:
• Vértice: x = 0 ⇒ y = 8
• Raíces (y=0): -0.5x² + 8 = 0 ⇒ x² = 16 ⇒ x = ±4
• Ancho total = x₂ - x₁ = 4 - (-4) = 8 m

2. Optimización (Derivadas)

Para encontrar un mínimo o máximo local, igualamos la primera derivada a cero ($A'(r) = 0$).

A(r) = 2πr² + 200π / r
A'(r) = 4πr - 200π / r²
4πr = 200π / r² ⇒ r³ = 50 ⇒ r = ∛50 ≈ 3.68 m (sin tapa)
*Nota: Con volumen ajustado V=100π, r_óptimo ≈ 4.64m
